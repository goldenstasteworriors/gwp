这是单人、单 packet 的离线标注工作台。它只接受预检绑定的状态目录、自己的 7 个 packet 文件和 12 段白名单视频；不会联网，也不会把媒体或标注发送到外部服务。

先由协调员运行严格预检并初始化状态目录。载入后身份与 session 锁定；本工具不做裁决、不改协议、不生成任何自动标签。

01

选择外部状态目录

目录必须含预检生成的 identity-locked session receipt；autosave 只写这里。

02

选择自己的 packet

只读取精确白名单；发现额外文件、媒体 hash 或身份不符时立即停止。

03

选择独立媒体目录

媒体不在 packet 内；目录只能含 receipt 绑定的 12 个只读 MP4。
