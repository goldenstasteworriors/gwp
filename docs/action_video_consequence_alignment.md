# 动作—视频后果对齐实验

## 控制目标

原始 WAM 的未来视频损失只要求共享 backbone 理解未来，并不要求动作头预测的动作与视频头描述的未来相容。因此，本实验不把目标定义为“让视频更服从动作”，而是把视频生成器当作一个可微的后果模型，用未来观测反向约束动作：如果动作头给出的动作会导向错误的未来，动作头应当收到梯度。

对带噪动作 `a_sigma`，动作头预测 flow `v_a`，得到当前 clean action 估计：

```text
a_hat = a_sigma - sigma_a * v_a
```

随后进行第二次、动作条件化的视频 forward：当前帧与任务不变，用 `a_hat` 作为条件预测真实未来视频的 flow，并计算后果损失 `L_consequence`。核心方法 `policy_only` 只保留

```text
d L_consequence / d a_hat * d a_hat / d theta_policy
```

而不让这次 forward 直接更新视频生成路径。这样优化目标仍然是动作头；视频模型在这里扮演可微评价器，而不是最终产品。

## 消融

| 名称 | 普通视频损失 | 动作损失 | 后果 forward | 后果梯度去向 |
|---|---:|---:|---:|---|
| `action_only` | 0 | 1 | 否 | 无 |
| `off` | 1 | 1 | 否 | 原始 GWP/WAM 基线 |
| `video_only` | 1 | 1 | 是 | 后果视频路径；动作预测值 detach |
| `joint` | 1 | 1 | 是 | 视频路径和动作路径 |
| `policy_only` | 1 | 1 | 是 | 只经预测动作回到 policy |

`video_only` 用来检验“把动作条件视频训练得更好”本身是否足够；`joint` 检验不做梯度隔离时两项目标是否互相干扰；`action_only` 检验普通未来视频辅助是否已经解释全部收益。

## 控制落地指标

只看动作 MSE 会忽略不同动作误差对机器人后果的差异，因此同时报告：

1. **闭环任务成功率**：LIBERO 固定初始状态上的实际控制结果。
2. **末端后果误差**：在 1/6/12/24/36/48 个控制步后，将预测动作 rollout 与专家 rollout 的末端位姿投影到主相机，计算像素误差和位移方向余弦。
3. **机械臂占据区域误差**：两套动作经 LIBERO OSC 控制器（对应 IK/控制效果）执行后，从 MuJoCo 几何体分割得到机械臂 mask，计算 IoU、Dice、质心误差。
4. **投影—视频一致性**：真实末端三维位移的相机投影，与视频分割中夹爪质心的实际位移比较，验证几何投影指标本身有物理意义。

机械臂 mask 比较前，使用排除机器人区域后的背景 ORB 特征估计 source-to-target homography，再将预测 mask 配准到真实帧。这个步骤只估计相机抖动，不能利用机器人特征把错误动作“配准正确”。

## 证伪标准

这个想法只有在以下结果同时出现时才值得继续：

- `policy_only` 相对 `off` 改善闭环成功率或控制后果指标；
- `policy_only` 优于或至少明显稳定于 `joint`；
- `video_only` 的提升弱于 `policy_only`，证明收益不是单纯来自更强的视频损失；
- 改善不能只出现在动作 MSE，必须落到末端投影、机械臂 mask 或任务成功率中的至少一项。

如果 `video_only` 与 `policy_only` 相当，说明共享 backbone 的普通辅助学习足以解释结果；如果所有方法只改善视频误差而不改善控制，则应放弃“后果对齐改善动作”的主张。
